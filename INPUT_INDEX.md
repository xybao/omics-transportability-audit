# Input index

reproduction_code/ACCEPTED_INPUTS.json records the fixed paths, file sizes and SHA-256 hashes for the 48 analytical inputs. It specifies the input contract rather than providing a data archive. DATA_ACCESS.md describes provider routes and conditional access to retained files.

For individual acquisition routes, consult INPUT_RECONSTRUCTION_STATUS.csv. INPUT_RECONSTRUCTION_GUIDE.md distinguishes verified operations from historical reconstruction that has not been tested end to end.

Full scientific evaluation also needs the two auxiliary GEO metadata extracts in SOURCE_RECORDS.md. These are additional to the 48-input manifest and are not redistributed. Public figure and table replay uses 42 retained result CSVs and exports 24 numerical tables; S20 and S21 are excluded.
