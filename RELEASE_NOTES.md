# Version 1.0.4

This repository preparation release accompanies the CBC v10 language manuscript. It separates source code, analysis results and figures into three independently extractable ZIP files. The scientific estimates and 48-input contract are unchanged from version 1.0.3-cbc-language.

Two complete GEO metadata extracts and the sample-level source mapping outputs for Tables S20 and S21 are excluded from public redistribution. Source routes and expected metadata hashes are provided instead. An explicit export option omits these two tables, and the scientific entry point checks for the two auxiliary metadata extracts before starting. These changes affect packaging and prerequisite checks, not estimation.

The public replay comprises 24 numerical CSV tables. Earlier references to 26 exported tables describe the complete local submission package, which also retains Tables S20 and S21. No historical model training or new scientific experiment was performed for this release.

The unpublished draft was updated on 9 October 2026 to record the reserved DOI and clarify author-directed code implementation and English language polishing. No scientific code, numerical result or figure changed. Version 1.0.4 is retained because this record has not yet been published.

The release documentation was aligned with the CBC submission on 9 October 2026. The authors confirmed that this research received no specific grant. The archive identifier, author-directed code implementation and English language polishing statements are consistent across the submission and distribution packages. Scientific code, numerical outputs and figures are unchanged.
